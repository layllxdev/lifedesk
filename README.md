# LifeDesk

Secretário pessoal digital para organizar tarefas, compromissos,
finanças e objetivos em um só lugar.

## Tecnologias

- Frontend: React + TypeScript
- Backend: Java + Spring Boot
- Banco de dados: PostgreSQL
- Ambiente: Docker
- Versionamento: Git

## Estrutura

- `frontend/`: aplicação web
- `backend/`: API e regras de negócio
- `database/`: migrações do banco de dados

## Objetivo

Desenvolver uma plataforma de organização pessoal com contas
independentes e proteção dos dados de cada usuário.
